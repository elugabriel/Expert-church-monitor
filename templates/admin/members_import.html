File Format

Both .csv and Excel .xlsx files work the same way. The first row must be a header. Only full_name is required — everything else is optional.

ColumnNotes
full_nameRequired
genderMale / Female
dob_dayBirthday day, 1–31
dob_monthBirthday month — number (1–12) or name (e.g. August)
phone
email
address
statusmember or first_timer (default: member)
member_numberLeave blank to auto-generate one

No birth year column on purpose — only day and month are ever collected. Rows missing a name, or with a member number that's already taken, are skipped and listed after import — the rest of the file still goes through.
